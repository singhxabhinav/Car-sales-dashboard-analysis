# 🚗 Car Sales Dashboard (Power BI)

Welcome to the **Car Sales Analysis Dashboard** project! This project uses **Power BI** to deliver clear and interactive insights into car sales data.

## 📊 Project Overview
This dashboard analyzes sales data for major car brands including Audi, BMW, Toyota, Skoda, and Hyundai. It helps visualize key business metrics and supports data-driven decision-making.

## 💡 Features
- **Key Metrics:** Total Revenue, Units Sold, and Number of Variants for each brand.
- **Top 5 Car Models by Revenue:** Highlighting the best-performing models.
- **Market Share Comparison:** Interactive visual breakdown of sales shares among different brands.
- **Sales Trend Analysis:** Yearly sales trends displayed to monitor growth and seasonality.
- **Market Brand Value:** Comparing overall brand sales revenue.
- **Interactive Filters:** Drill-down options to explore specific brands and models.

## 🛠️ Tools & Technologies
- **Power BI Desktop**
- **Data Modeling**
- **DAX (Data Analysis Expressions)**
- **Visualizations:** Bar Charts, Line Charts, KPI Cards, Slicers

## 📂 Files Included
- **`carsalesdashboard.pbix`** - Complete Power BI project file.
- **`carsalesdashboard.pdf`** - Dashboard snapshots for reference.

## 🔗 How to Use
1. Open the `.pbix` file in Power BI Desktop.
2. Explore the dashboard using filters and slicers.
3. Analyze key sales insights across different brands and time periods.
